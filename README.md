# URL GIF / MP4 다운로더

X(Twitter)를 비롯해 `yt-dlp`가 지원하는 공개 동영상 링크를 MP4 또는 GIF로 저장합니다.

## 사용법

이 폴더에서 PowerShell 터미널을 열고 다음 중 하나를 실행하세요.

```powershell
.\download.ps1 "https://x.com/i/status/2103358175319916606" mp4
```

```powershell
.\download.ps1 "https://x.com/i/status/2103358175319916606" gif
```

- `mp4`를 생략하면 기본으로 MP4를 받습니다.
- MP4 결과는 `MP4` 폴더에 저장됩니다.
- GIF 결과는 `GIF` 폴더에 저장됩니다.
- 최초 실행 때만 프로젝트 내부에 다운로드 도구를 자동 설치합니다.

URL에 `&` 같은 문자가 포함될 수 있으므로 URL 전체를 큰따옴표로 감싸 주세요.

## 참고

- 공개 게시물만 받을 수 있습니다. 비공개이거나 로그인이 필요한 게시물은 실패할 수 있습니다.
- GIF는 초당 15프레임, 최대 너비 960px로 먼저 변환됩니다.
- 결과가 10MB(10,000,000바이트)를 넘으면 12fps 용량을 기존 용량의 80%로 예상합니다.
- 예상 용량이 10MB 이하면 해상도를 유지하고 12fps로 한 번 재변환합니다.
- 예상 용량도 10MB를 넘으면 `√(10MB / 예상 용량) × 0.95` 비율로 가로·세로를 함께 줄여 12fps로 한 번 재변환합니다. 0.95는 추정 오차를 위한 여유분입니다.
- 재변환은 최대 한 번만 합니다. 실제 결과가 예상과 달리 10MB를 넘으면 용량 안내를 출력하고 해당 결과를 저장합니다.
- 콘텐츠를 내려받을 권리가 있는지 확인하고 서비스 약관과 저작권을 준수하세요.
